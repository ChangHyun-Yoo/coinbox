# 저금통 과제 면접 준비

이 폴더는 제출 산출물을 변경하지 않고, 저금통 과제를 설명하고 설계 판단을 방어하기 위한 개인 면접 준비 자료입니다.

## 1. 작성 기준

- 기준일은 2026년 9월 14일이며, 프로젝트의 최종 소스와 기존 문서를 확인하여 작성했습니다.
- 질문과 설명은 제출된 구조와 동작을 기준으로 하며, 개발 중간의 설계 변경이나 문제 해결 이력은 다루지 않습니다.
- 예상 답변은 말하기 연습용 초안입니다. 개인적인 선택 동기, 실제 기여 범위와 경험은 본인의 사실에 맞게 조정합니다.
- 현재 구현, 설계 의도, 추가 검증이 필요한 지점, 향후 개선안을 구분합니다.
- 이 문서 작성 과정에서는 애플리케이션 코드와 기존 제출 문서를 수정하거나 테스트를 새로 실행하지 않았습니다.
- 카카오뱅크 내부 구현이나 실제 면접 문항을 알고 있다는 전제로 작성하지 않았습니다. 금융 규칙은 이 과제의 구현 범위를 설명합니다.
- 총 9개 문서에 핵심 예상 질문·답변 85개와 상황형 질문 10개를 정리했습니다.
- 외부 공식 문서는 개념 확인용입니다. 일부 링크는 MySQL 8.4 또는 현재 Spring 문서이므로 프로젝트가 사용하는 버전과 동일한 실행 환경이라고 가정하지 않습니다.

## 3. 학습 방법

먼저 1번과 2번 문서를 읽고 자료 없이 업무 전체를 설명합니다. 이후 질문에 대해 `결론 → 구현 근거 → 선택 이유 → 한계` 순서로 30~60초 답변을 연습합니다. 구현 근거는 각 문서의 소스 링크로 확인합니다. 기술 용어 정의만 외우지 않고, 같은 현상이 이 과제의 어느 요청과 테이블에서 발생하는지 연결합니다.

시간이 부족하면 전체 흐름, 고객 잠금, 두 계좌의 이체 원자성, 동전모으기 멱등성, 정책 캐시, 실패 복구의 한계를 우선 준비합니다. Kafka·Redis 등 미사용 기술의 상세 설명보다 실제 구현과 선택의 근거가 우선입니다.
